線性規劃的假設與標準形式

線性規劃（linear programming，LP）是目標函數與限制式都是線性的最佳化模型。把真實問題寫成 LP 之前，要先確認它大致符合四個假設：

假設意思什麼時候不成立
比例性（proportionality）產量加倍，利潤與資源用量也加倍大量採購有折扣、有固定的開機成本
可加性（additivity）總量等於各產品分別貢獻的總和兩種產品一起做會互相干擾或互補
可分割性（divisibility）變數可以是小數機器台數、人數必須是整數
確定性（certainty）所有參數都是已知常數需求、處理時間有不確定性

本講義把最大化、限制式全部是「$\le$」且變數非負的模型稱為標準形式：

$$\begin{aligned} \max \quad & Z = \sum_{j=1}^{n} c_j x_j \\ \text{s.t.} \quad & \sum_{j=1}^{n} a_{ij} x_j \le b_i, \quad i = 1, \dots, m \\ & x_j \ge 0, \quad j = 1, \dots, n \end{aligned}$$

用矩陣寫更精簡：$\max\ Z = \mathbf{c}^{\mathsf{T}}\mathbf{x}$，s.t. $A\mathbf{x} \le \mathbf{b}$，$\mathbf{x} \ge \mathbf{0}$。其中 $c_j$ 是單位利潤，$a_{ij}$ 是第 $j$ 個活動每單位用掉第 $i$ 種資源的量，$b_i$ 是第 $i$ 種資源的可用量。

例題：Wyndor 玻璃公司

例題 2-1：Wyndor 玻璃公司的產品組合

Wyndor 玻璃公司打算推出兩種新產品：產品 1 是鋁框玻璃門，產品 2 是木框窗戶。工廠 1 做鋁框、工廠 2 做木框、工廠 3 負責玻璃與組裝。每批產品需要的工時、各工廠每週剩餘的可用工時與每批利潤如下表。每週各生產幾批，利潤最高？

產品 1（小時／批）產品 2（小時／批）每週可用（小時）
工廠 1104
工廠 20212
工廠 33218
每批利潤（千元）35

解：先建模

令 $x_1$、$x_2$ 為每週生產產品 1、產品 2 的批數：

$$\begin{aligned} \max \quad & Z = 3x_1 + 5x_2 \\ \text{s.t.} \quad & x_1 \le 4 \\ & 2x_2 \le 12 \\ & 3x_1 + 2x_2 \le 18 \\ & x_1,\ x_2 \ge 0 \end{aligned}$$

接下來用圖解法求解，步驟在下一節。

圖解法

只有兩個變數時，可以把可行解區域畫在平面上，直接看出最佳解：

  1. 非負限制 $x_1, x_2 \ge 0$ 讓我們只看第一象限。
  2. 每條限制式先畫出等號成立的直線，再代入原點 $(0, 0)$ 判斷哪一側可行。
  3. 所有可行側的交集就是可行解區域，下圖的綠色多邊形。
  4. 畫一條等利潤線 $3x_1 + 5x_2 = Z$，往利潤增加的方向（箭頭）平移；離開可行解區域前最後碰到的點，就是最佳解。

等利潤線最後碰到的是 $2x_2 = 12$ 與 $3x_1 + 2x_2 = 18$ 的交點。聯立解得 $x_2 = 6$、$x_1 = 2$，所以最佳解是 $(x_1, x_2) = (2, 6)$，$Z^* = 3 \times 2 + 5 \times 6 = 36$，也就是每週利潤 36 千元。

角點定理

把可行解區域的五個頂點都代進目標函數，可以驗證圖解法的答案：

頂點 $(x_1, x_2)$$Z = 3x_1 + 5x_2$
$(0, 0)$0
$(4, 0)$12
$(4, 3)$27
$(2, 6)$36
$(0, 6)$30

定理：角點定理（corner-point theorem）

如果線性規劃有最佳解，而且可行解區域至少有一個頂點，那麼一定有某個頂點（角點）是最佳解。

可行解區域裡有無限多個點，但頂點只有有限多個。角點定理告訴我們：只要在頂點之間找就好。第 3 課的單形法就是一個「有系統地從一個頂點走到更好的相鄰頂點」的方法。

圖 2-1 的滑桿也透露了另一件事：當 $c_1$ 在 0 到 7.5 之間時，最佳解一直停在 $(2, 6)$。原因是等利潤線的斜率 $-c_1/5$ 只要介於限制式 $2x_2 = 12$ 的斜率 0 與 $3x_1 + 2x_2 = 18$ 的斜率 $-3/2$ 之間，最後碰到的就是同一個頂點。這種「參數改變多少答案才會變」的分析叫做敏感度分析（sensitivity analysis）。

三種特殊情況

不是每個線性規劃都有唯一的最佳解，求解時要能認出下面三種情況：

情況圖上看起來常見原因
無可行解（infeasible）所有限制式沒有共同區域需求下限大於產能上限
無界（unbounded）可行解區域往目標改善的方向無限延伸漏寫了某個資源限制
多重最佳解（multiple optima）等利潤線與可行解區域的一整條邊重合目標函數與某條限制式平行

動手試試

把圖 2-1 的滑桿拉到 7.5，等利潤線會和 $3x_1 + 2x_2 = 18$ 重合，從 $(2, 6)$ 到 $(4, 3)$ 整條邊都是最佳解。

用 Python 求解

變數一多就不能畫圖了，實務上會交給求解器。下面用 PuLP 套件解例題 2-1，PuLP 會呼叫內建的 CBC 求解器：

# 例題 2-1：Wyndor 玻璃公司（安裝：pip install "pulp<4"）
import pulp

model = pulp.LpProblem("Wyndor", pulp.LpMaximize)

# 決策變數：每週生產的批數
x1 = pulp.LpVariable("x1", lowBound=0)  # 產品 1：鋁框玻璃門
x2 = pulp.LpVariable("x2", lowBound=0)  # 產品 2：木框窗戶

# 目標函數：每週利潤（千元）
model += 3 * x1 + 5 * x2, "Profit"

# 限制式：三座工廠的可用時數
model += x1 <= 4, "Plant1"
model += 2 * x2 <= 12, "Plant2"
model += 3 * x1 + 2 * x2 <= 18, "Plant3"

model.solve(pulp.PULP_CBC_CMD(msg=False))

print("狀態：", pulp.LpStatus[model.status])
print("x1 =", x1.value(), "，x2 =", x2.value())
print("Z* =", pulp.value(model.objective))
# 輸出：
# 狀態： Optimal
# x1 = 2.0 ，x2 = 6.0
# Z* = 36.0

版本注意

PuLP 4 改寫了建立變數的寫法，也不再內建 CBC 求解器，上面的程式會出錯。本講義的程式一律以 pip install "pulp<4" 安裝的 3.x 版為準。

重點整理

  • 線性規劃假設比例性、可加性、可分割性與確定性。
  • 圖解法：畫出可行解區域，把等目標線往改善方向平移，最後碰到的點就是最佳解。
  • 角點定理：有最佳解時，一定有頂點是最佳解，所以只需比較有限個頂點。
  • 線性規劃可能無可行解、無界，或有多重最佳解。
  • 實務上用求解器（例如 PuLP 搭配 CBC）求解，記得安裝 pulp<4。

練習題

練習 2-1用圖解法求例題 1-1（手搖飲店）的最佳解：$\max Z = 20x_1 + 30x_2$，s.t. $x_1 + x_2 \le 500$，$x_2 \le 200$，$x_1, x_2 \ge 0$。

解答

可行解區域的頂點是 $(0, 0)$、$(500, 0)$、$(300, 200)$、$(0, 200)$，對應的利潤分別是 0、10,000、12,000、6,000 元。最佳解是 $(x_1, x_2) = (300, 200)$，$Z^* = 12{,}000$ 元。

練習 2-2例題 2-1 中，如果工廠 3 每週的可用工時從 18 小時增加到 20 小時，最佳解與 $Z^*$ 會變成多少？

解答

最佳解仍落在 $2x_2 = 12$ 與 $3x_1 + 2x_2 = 20$ 的交點：$x_2 = 6$、$x_1 = 8/3 \approx 2.67$，且滿足 $x_1 \le 4$。$Z^* = 3 \times \tfrac{8}{3} + 5 \times 6 = 38$。工廠 3 多 2 小時，利潤多 2 千元，代表工廠 3 每多 1 小時值 1 千元，這個數字叫做影子價格（shadow price），第 3 課的單形表會再看到它。

練習 2-3$\max Z = x_1 + x_2$，s.t. $x_1 - x_2 \le 1$，$x_1, x_2 \ge 0$。這個問題的最佳解是什麼？

解答

沒有最佳解，問題是無界的。例如令 $x_1 = 0$，$x_2$ 可以任意變大而不違反限制式，$Z$ 也跟著無限增加。實務上遇到無界，通常代表漏寫了某個資源限制。
