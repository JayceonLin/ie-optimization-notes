學習目標

讀完這一課，你應該能夠：

  • 加入寬鬆變數，把「$\le$」限制式改寫成等式。
  • 分辨基變數與非基變數，說明基本可行解和頂點的關係。
  • 用單形表完成轉軸：選進入變數、做最小比值檢定、選離開變數。
  • 從最終單形表讀出最佳解與影子價格。

單形法的想法

第 2 課的角點定理說：最佳解一定可以在頂點找到。但變數一多，頂點數量會爆炸，不可能一一列出來比較。單形法（simplex method）的做法像爬山：

  1. 從一個頂點出發，通常是原點。
  2. 看看相鄰的頂點裡，有沒有讓目標函數更好的。
  3. 有的話就沿著邊走過去；沒有的話，目前的頂點就是最佳解。

線性規劃的可行解區域是凸的，所以「相鄰頂點都沒有更好」就保證是整體最佳，不會卡在局部最佳。以 Wyndor 為例，單形法會走 $(0, 0) \to (0, 6) \to (2, 6)$，只比較了 3 個頂點就停下來。

寬鬆變數與基本可行解

要用代數的方式「沿著邊走」，先把不等式變成等式。每條「$\le$」限制式加上一個非負的寬鬆變數：

$$\begin{aligned} x_1 \phantom{{}+2x_2} + s_1 &= 4 \\ 2x_2 + s_2 &= 12 \\ 3x_1 + 2x_2 + s_3 &= 18 \\ x_1, x_2, s_1, s_2, s_3 &\ge 0 \end{aligned}$$

定義：寬鬆變數（slack variable）

$s_i$ 代表第 $i$ 種資源沒用完的量。例如 $s_1 = 4 - x_1$ 是工廠 1 剩下的工時。注意不要和第 4 課的「LP 鬆弛」搞混，兩者是不同概念。

現在有 3 條等式、5 個變數。任選 2 個變數設為 0，剩下 3 個就能解出唯一的值：

定義：基變數、非基變數、基本可行解

設為 0 的變數叫非基變數（nonbasic variable），解出來的變數叫基變數（basic variable）。這樣得到的解叫基本解；如果所有變數都 $\ge 0$，就是基本可行解（basic feasible solution，BFS）。每個基本可行解剛好對應可行解區域的一個頂點。

例如令 $x_1 = x_2 = 0$，得到 $s_1 = 4$、$s_2 = 12$、$s_3 = 18$，對應頂點 $(0, 0)$：什麼都不生產，所有工時都沒用。

例題：用單形表解 Wyndor

例題 3-1：Wyndor 玻璃公司的單形表

用單形法求解例題 2-1：$\max Z = 3x_1 + 5x_2$，s.t. $x_1 \le 4$，$2x_2 \le 12$，$3x_1 + 2x_2 \le 18$，$x_1, x_2 \ge 0$。

解：第 0 次迭代（原點）

把目標函數改寫成 $Z - 3x_1 - 5x_2 = 0$ 放在第一列，寬鬆變數當初始基變數。Z 列中最負的係數是 $x_2$ 的 $-5$（每多做 1 批產品 2，利潤增加 5），所以 $x_2$ 是進入變數，下表灰色欄。

從最終單形表讀出更多資訊

最終單形表不只給答案，還藏著管理上很有用的數字：

  • 寬鬆變數的值：$s_1 = 2$ 表示工廠 1 每週還有 2 小時沒用到；$s_2 = s_3 = 0$ 表示工廠 2、3 的工時用完了，它們是瓶頸資源。
  • 影子價格：Z 列在 $s_1, s_2, s_3$ 底下的數字 $0, \tfrac{3}{2}, 1$，就是三座工廠每多 1 小時能增加的利潤（千元）。第 2 課練習 2-2 把工廠 3 加 2 小時、利潤多 2，正好對上這裡的 1。

管理意義

如果要花錢加班，應該優先加在影子價格最高的工廠 2；工廠 1 的影子價格是 0，加班完全沒有好處。

單形法步驟整理

  1. 建立初始單形表：每條限制式加寬鬆變數，寬鬆變數當基變數，目標函數改寫成 $Z - \sum c_j x_j = 0$。
  2. 最佳性檢查：Z 列的係數都 $\ge 0$ 就停止，目前的解就是最佳解。
  3. 選進入變數：挑 Z 列中最負的係數所在的欄。
  4. 選離開變數：對進入變數欄中係數為正的列做最小比值檢定，比值最小的列的基變數離開。
  5. 轉軸：樞紐列除以樞紐元素，再用列運算把該欄其他數字消成 0，回到步驟 2。

常見錯誤

比值檢定時把係數為 0 或負數的列也算進來。這些列不會限制進入變數增加，必須跳過。如果進入變數那一欄完全沒有正係數，代表問題是無界的。

本課只處理標準形式。遇到「$\ge$」或「$=$」限制式時，原點不是可行解，需要先用大 M 法（Big-M method）或兩階段法（two-phase method）找到起始的基本可行解，可以參考延伸閱讀的教科書。

重點整理

  • 寬鬆變數把「$\le$」限制式變成等式，它的值就是沒用完的資源。
  • 每個基本可行解對應一個頂點；單形法每次轉軸就是走到相鄰的頂點。
  • 進入變數看 Z 列最負的係數，離開變數看最小比值（只算正係數）。
  • Z 列沒有負數時停止；寬鬆變數欄的 Z 列係數就是影子價格。

練習題

練習 3-1用單形法求解例題 1-1（手搖飲店）：$\max Z = 20x_1 + 30x_2$，s.t. $x_1 + x_2 \le 500$，$x_2 \le 200$，$x_1, x_2 \ge 0$。

解答

初始 Z 列為 $(-20, -30, 0, 0 \mid 0)$。第一次 $x_2$ 進入，比值 $500/1 = 500$、$200/1 = 200$，$s_2$ 離開；轉軸後 Z 列為 $(-20, 0, 0, 30 \mid 6000)$，$s_1$ 列為 $(1, 0, 1, -1 \mid 300)$。第二次 $x_1$ 進入，只有 $s_1$ 列係數為正，$s_1$ 離開；轉軸後 Z 列為 $(0, 0, 20, 10 \mid 12000)$，沒有負數，停止。最佳解 $x_1 = 300$、$x_2 = 200$、$Z^* = 12{,}000$ 元。

練習 3-2例題 3-1 的第一次迭代如果改選 $x_1$ 當進入變數（它的係數 $-3$ 也是負的），單形法會經過哪些頂點？

解答

$x_1$ 進入時比值為 $4/1 = 4$（$s_1$ 列）與 $18/3 = 6$（$s_3$ 列），$s_1$ 離開，走到 $(4, 0)$，$Z = 12$。接著 $x_2$ 進入、$s_3$ 離開，走到 $(4, 3)$，$Z = 27$。這時 Z 列在 $s_1$ 底下是 $-9/2$，$s_1$ 再進入、$s_2$ 離開，走到 $(2, 6)$，$Z = 36$。路徑是 $(0,0) \to (4,0) \to (4,3) \to (2,6)$，比原本多一次迭代，但答案相同。「選最負的係數」只是經驗法則，不保證步數最少。

練習 3-3在表 3-3 中，為什麼工廠 1 的影子價格是 0？

解答

因為 $s_1 = 2 > 0$，工廠 1 本來就還有 2 小時沒用完。再多給它工時，也只是增加更多用不到的時間，最佳解和利潤都不會改變，所以影子價格是 0。只有用完的瓶頸資源（$s_i = 0$）才可能有正的影子價格。
