學習目標

讀完這一課，你應該能夠：

  • 說明什麼情況需要整數變數或 0-1 變數。
  • 解釋為什麼把 LP 的答案四捨五入不一定得到最佳整數解。
  • 用 0-1 變數寫出「最多選幾個」「互斥」「依賴」「固定成本」等條件。
  • 說出分支界限法的分支、定界與剪枝。

為什麼需要整數

第 2 課的可分割性假設允許變數是小數，但很多決策天生就不能切開：

  • 不可分割的數量：要買幾台機器、排幾個班、派幾輛車。
  • 是或否的決策：要不要蓋新廠、要不要投資某個專案、某張訂單要不要接。這種決策用只能是 0 或 1 的變數表示。

定義：整數規劃（integer programming，IP）

目標函數與限制式都是線性，但部分或全部變數必須是整數的模型。全部變數都是整數叫純整數規劃；只有部分是整數叫混合整數規劃（MIP）；變數只能是 0 或 1 叫 0-1 整數規劃（binary integer programming）。

四捨五入的陷阱

最直覺的做法是：先當成一般 LP 解，再把答案四捨五入。下面的例子說明這樣可能錯得很遠。

例題 4-1：四捨五入不一定可行，也不一定最好

求解 $\max Z = x_1 + 5x_2$，s.t. $x_1 + 10x_2 \le 20$，$x_1 \le 2$，$x_1, x_2 \ge 0$ 且為整數。

解

先拿掉整數限制求解，得到 $(x_1, x_2) = (2, 1.8)$，$Z = 11$。接著比較幾個候選答案：

做法$(x_1, x_2)$結果
四捨五入$(2, 2)$$2 + 20 = 22 > 20$，不可行
無條件捨去$(2, 1)$可行，$Z = 7$
真正的最佳整數解$(0, 2)$可行，$Z = 10$

最佳整數解 $(0, 2)$ 離 LP 的答案 $(2, 1.8)$ 很遠，靠四捨五入完全找不到。

定義：LP 鬆弛（LP relaxation）

把整數規劃的整數限制拿掉後得到的線性規劃。它的可行解區域比原問題大，所以對最大化問題而言，LP 鬆弛的最佳值是整數規劃最佳值的上界：例題 4-1 中 $11 \ge 10$。

分支界限法

整數解的組合太多，不能全部列舉。分支界限法（branch and bound）用 LP 鬆弛幫忙，把搜尋空間一刀一刀切開，並把不可能更好的部分整個丟掉：

  1. 定界：解目前子問題的 LP 鬆弛，它的最佳值是這個子問題能達到的上界。
  2. 分支：如果答案中有變數不是整數，例如 $x_2 = 1.8$，就切成 $x_2 \le 1$ 與 $x_2 \ge 2$ 兩個子問題。中間的 $1 < x_2 < 2$ 本來就沒有整數解，丟掉沒有損失。
  3. 剪枝：子問題不可行、上界不比目前找到的最佳整數解好，或答案已經是整數時，這個子問題就不必再往下分。

用例題 4-1 走一次：

表 4-1　例題 4-1 的分支界限過程
節點加入的限制LP 鬆弛的解$Z$處理
0（根）無$(2, 1.8)$11$x_2$ 不是整數，分支
1$x_2 \le 1$$(2, 1)$7整數解，目前最佳 $Z = 7$
2$x_2 \ge 2$$(0, 2)$10整數解且比 7 好，更新為 $Z = 10$

所有節點都處理完，最佳整數解是 $(0, 2)$，$Z^* = 10$。實務上的求解器（例如 PuLP 背後的 CBC）用的就是分支界限法加上許多加速技巧。

0-1 變數的建模技巧

0-1 變數真正厲害的地方是能把「邏輯條件」寫成線性限制式。令 $y_A, y_B, \dots \in \{0, 1\}$，1 代表選擇、0 代表不選：

想表達的條件限制式
最多選 $k$ 個$\sum_i y_i \le k$
A、B 至少選一個$y_A + y_B \ge 1$
A、B 不能同時選（互斥）$y_A + y_B \le 1$
選 A 就必須選 B（依賴）$y_A \le y_B$
有生產才付固定成本 $f$，產量上限 $M$成本 $f y + c x$，且 $x \le M y$

最後一列的 $x \le My$ 是常見的大 M 限制式：$y = 0$ 時強迫 $x = 0$；$y = 1$ 時 $x$ 最多到 $M$，等於沒有額外限制。

常見錯誤

為了保險把 $M$ 設成 $10^9$。$M$ 太大會讓 LP 鬆弛變得很鬆、分支界限法剪不掉節點，也容易出現數值誤差。$M$ 應該取變數實際可能的上限，例如產能。

例題：投資專案選擇

例題 4-2：預算有限時要投資哪些專案

公司有 4 個候選專案，總預算 14 百萬元，每個專案只能全投或不投。(a) 要投資哪些專案，總淨現值（NPV）最大？(b) 如果專案 D 的技術需要專案 A 先完成，也就是「選 D 就必須選 A」，答案會怎麼變？

專案ABCD
投資金額（百萬元）5743
淨現值（百萬元）81164

解

令 $y_k = 1$ 代表投資專案 $k$，否則為 0：

$$\begin{aligned} \max \quad & Z = 8y_A + 11y_B + 6y_C + 4y_D \\ \text{s.t.} \quad & 5y_A + 7y_B + 4y_C + 3y_D \le 14 \\ & y_A, y_B, y_C, y_D \in \{0, 1\} \end{aligned}$$

(a) 最佳解是投資 B、C、D，剛好用完 14 百萬元，總淨現值 $Z^* = 21$ 百萬元。

(b) 加上依賴限制 $y_D \le y_A$ 後，B、C、D 的組合不再可行，最佳解變成投資 A、B，總淨現值 $Z^* = 19$ 百萬元。

為什麼不能照「CP 值」挑

依淨現值除以金額排序是 A（1.6）、B（1.57）、C（1.5）、D（1.33）。依序挑 A、B 之後預算剩 2，C、D 都放不下，只得到 19，比 (a) 的 21 差。貪婪地挑 CP 值最高的，不保證最佳。

用 PuLP 求解時，把變數宣告成 cat="Binary" 即可：

# 例題 4-2：投資專案選擇（安裝：pip install "pulp<4"）
import pulp

projects = ["A", "B", "C", "D"]
cost = {"A": 5, "B": 7, "C": 4, "D": 3}   # 投資金額（百萬元）
npv = {"A": 8, "B": 11, "C": 6, "D": 4}   # 淨現值（百萬元）
budget = 14

model = pulp.LpProblem("CapitalBudgeting", pulp.LpMaximize)
y = pulp.LpVariable.dicts("y", projects, cat="Binary")  # 1 = 投資，0 = 不投資

model += pulp.lpSum(npv[k] * y[k] for k in projects), "TotalNPV"
model += pulp.lpSum(cost[k] * y[k] for k in projects) <= budget, "Budget"
# 想加入「選 D 就必須選 A」時，把下一行的 # 拿掉
# model += y["D"] <= y["A"], "D_requires_A"

model.solve(pulp.PULP_CBC_CMD(msg=False))

chosen = [k for k in projects if y[k].value() > 0.5]
print("投資專案：", chosen)
print("總淨現值：", pulp.value(model.objective))
# 輸出：（不含依賴限制）
# 投資專案： ['B', 'C', 'D']
# 總淨現值： 21.0

重點整理

  • 不可分割的數量用整數變數，是或否的決策用 0-1 變數。
  • 把 LP 答案四捨五入可能不可行，也可能離最佳解很遠。
  • LP 鬆弛的最佳值是整數規劃最佳值的界限（最大化時是上界）。
  • 分支界限法：用 LP 鬆弛定界、對非整數變數分支、把沒希望的子問題剪掉。
  • 0-1 變數可以表達選幾個、互斥、依賴與固定成本；大 M 要取合理的上限。

練習題

練習 4-1延續例題 4-2，用 0-1 變數寫出下列條件：(a) A、B、C 三個專案最多選兩個；(b) B 與 C 不能同時選；(c) 選了 C 就必須選 A。

解答

(a) $y_A + y_B + y_C \le 2$；(b) $y_B + y_C \le 1$；(c) $y_C \le y_A$。

練習 4-2某產線每生產 1 單位成本 50 元，但只要當天開工就要先付 2,000 元的開機費，每天產能上限 300 單位。請寫出每日成本與相關限制式。

解答

令 $x$ 為當天產量，$y \in \{0, 1\}$ 表示是否開工。每日成本為 $2000y + 50x$，限制式為 $x \le 300y$，$x \ge 0$。這裡的大 M 直接取產能 300：不開工時 $x$ 必須是 0，開工時最多生產 300 單位。

練習 4-3例題 4-1 中，LP 鬆弛的最佳值 11 告訴我們什麼？如果分支界限法在某個節點得到 LP 鬆弛值 9.5，而目前已經找到 $Z = 10$ 的整數解，該怎麼處理這個節點？

解答

11 是整數規劃最佳值的上界：任何整數解的 $Z$ 都不會超過 11。若某節點的上界只有 9.5，它底下所有整數解都不會超過 9.5，不可能比已經找到的 10 好，所以直接剪枝，不用再分支。
